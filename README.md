# Example tools — AI coding for problem solving

**Live: https://carynamichel-hue.github.io/examples/**

One page listing the example tools for the session: what problem each one
started from, a link to open it, and a link to how it was built (the
`prompts/` folder for Degree Days and Scout Report, the commit history for
the others).

`examples-qr.svg` (print) and `examples-qr.png` point at this page.
To add or change a tool, edit the `tools` list in `index.html`'s cards.
